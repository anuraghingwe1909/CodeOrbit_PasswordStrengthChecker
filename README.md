# CodeOrbit Password Strength Checker

A simple Python-based Password Strength Checker developed as part of the CodeOrbit Tech Cyber Security Internship.

## Features

- Checks password length
- Checks uppercase letters
- Checks lowercase letters
- Checks numbers
- Checks special characters
- Displays password strength
- Provides suggestions to improve weak passwords

## Requirements

- Python 3.x

## How to Run

```bash
python password_strength_checker.py
